# Vendored MediaSliderView

This directory contains the local media-viewing module used by Immich TV Private.
The root build includes `:mediaslider:mediaslider` directly; it does not fetch this
module as a Git submodule or use the original hosted demo media.

Build and usage instructions for this application are in the [root README](../README.md).
The legacy `app/` example is not part of the root build and has no bundled remote
sample media. It is retained only as reference code, not a supported standalone app.
