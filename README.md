# Immich TV Private

面向自托管 Immich 的 Android TV 私用分支。

- [下载 APK 和对应源码](https://github.com/z979054461/Immich-Android-TV/releases)
- [查看私用版代码、使用说明与构建方法](https://github.com/z979054461/Immich-Android-TV/tree/feature/private-selfhosted)

当前私用版在 `feature/private-selfhosted` 分支开发。此 `main` 分支保留上游历史代码，不是当前安装或构建入口；请以上述开发分支与发行版说明为准。

## 许可与来源

本项目基于 [giejay/Immich-Android-TV](https://github.com/giejay/Immich-Android-TV)，保留 [GPLv3 许可](LICENSE)、原始版权与必要署名；内置 mediaslider 保留其 Apache-2.0 许可。此为非官方个人分支，不是 Immich 官方电视客户端。
